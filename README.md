# Projet Starter TypeScript / Web 🚀

Modèle de départ minimaliste et structuré pour initialiser rapidement un projet web moderne avec TypeScript.

## 📁 Structure du projet
- `index.html` : Structure HTML5 de base
- `style.css` : Feuille de styles CSS3
- `script.js` / TypeScript : Point d'entrée des scripts applicatifs

## 🛠️ Technologies
- **TypeScript / JavaScript**
- **HTML5 & CSS3**
